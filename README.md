# Picture Gallery

Galería personal de **Santyago Amozurrutia Monter**, hecha con HTML y CSS puro (tema rojo y negro).

Secciones: Carrera, Sueños, Películas, Cantantes, Pasatiempos y Fotos, cada una con su texto y sus imágenes.

## Cómo verla

- **En línea:** con GitHub Pages activado, en `https://<tu-usuario>.github.io/<nombre-del-repo>/`
- **En tu computadora:** abre `index.html` con doble clic.

## Estructura

```
index.html      página principal
styles.css      estilos
carrera/        imágenes de Carrera
suenos/         imágenes de Sueños
peliculas/      imágenes de Películas
artistas/       imágenes de Cantantes
pasatiempos/    imágenes de Pasatiempos
images/         fotos personales
```
